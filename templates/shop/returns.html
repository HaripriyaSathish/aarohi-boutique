Returns & exchanges

Need a different fit?

Request a return or size exchange from a delivered order within the store’s return window (default 7 days). Keep items unused with original tags. Approval, pickup and inspection are handled by the store.

Refunds

Cancellation is available before packing. Paid cancellations require refund processing. After inspection, refunds are sent to the original payment method. Processing times depend on the bank. Individual order-line refunds are supported. After delivery, the original shipping fee is non-refundable. Each request covers all units of its selected order line.
